# LandslideGuard

AI-Powered Landslide Risk Detection and Early Warning System

## Project Overview

LandslideGuard is a technology platform designed to detect, analyze, and predict landslide risks using machine learning, GIS, satellite data, and real-time information.

## Tech Stack

- Frontend: React + Leaflet
- Backend: FastAPI
- Machine Learning: Python
- Database: PostgreSQL + PostGIS
- Mobile: Flutter
- Cloud: AWS

## Project Structure

- `frontend/` - React web application
- `backend/` - FastAPI backend
- `ml/` - Machine learning models and pipelines
- `mobile/` - Flutter citizen application
- `data/` - Datasets and geospatial data
- `database/` - PostgreSQL/PostGIS schema and seeds
- `docs/` - Project documentation
- `scripts/` - Utility scripts
